
## Traffic-control-RL

В данном проекте реализуется среда управления светофором (Traffic Light Environment) и использует алгоритм Actor-Critic , чтобы обучить агента оптимальному переключению сигналов светофора для минимизации очередей транспорта.
* * *
### Анализ данных:
Среда Gym : реализована кастомная среда TrafficLightEnv для моделирования перекрёстка.
Очереди транспорта : на каждой стороне перекрёстка динамически изменяется количество автомобилей.
Визуализация состояния : графическое отображение очередей и текущего направления светофора.
* * *
### Обучение с подкреплением:
Алгоритм : использован метод Actor-Critic для обучения агента принимать оптимальные решения.
Награды :
"плюс" за пропуск машин,
"минус" за ненужное переключение,
"минус" за выбор неэффективного направления,
"плюс"за уменьшение общей очереди.
Обучение проводится в течение 4000 эпизодов .
Тестирование модели :
выводятся примеры действий агента,
анализируются правильные / неправильные решения,
оценивается общая проходимость транспорта.
* * *
### Архитектура моделей:
Actor : полносвязная нейросеть с dropout и активацией GELU. Выдаёт вероятности действий.
Critic : полносвязная сеть аналогичной структуры. Оценивает значение состояния.
Функция потерь : MSE для Critic, Policy Gradient для Actor.
Оптимизаторы : AdamW с разными скоростями обучения.
* * *
### Визуализация и логирование:
Графики :
история наград,
сравнение правильных и неправильных решений.
Отрисовка шагов :
сохранение изображений состояний и действий агента в папку /frames.
отображение результатов тестирования в виде таблицы "состояние / действие".
* * *
### Результаты:
Агент обучается эффективно управлять светофором.
Демонстрация высокой точности принятия решений при наличии очередей.
Поддерживается баланс между количеством переключений и пропускной способностью.
